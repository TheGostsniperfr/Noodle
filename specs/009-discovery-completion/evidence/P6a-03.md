## Findings

These are minor and break no criterion.

- **The verify step only works with `-observed-at`.** In `docs/features.json:49`, the verify command as written omits `-observed-at`. Without it, the output differs from the golden file on the `provenance.observedAt` timestamp, and `diff` exits 1. The contract and the Makefile both pass `-observed-at 2026-11-04T00:00:00Z`, so the graded criteria hold. The entry is immutable under C12, so the fix is to document in `docs/COMMANDS.md` or the example's header that the golden file is pinned to that timestamp.
- **`kubectl-list` renames the List file.** In `cmd/noodle/example_test.go:46-55`, the subtest copies `list.yaml` into a temp directory under the name `manifests/platform.yaml`, so the `src.file` paths match the golden file. It proves the List is decoded to the same fragment. It does not prove that discovery run on `examples/discovery-k8s/list.yaml` in place gives the golden file, because the `src` paths would differ. This is acceptable for DSC-05 #1 as written, and is worth keeping in mind when grading P6a-04.

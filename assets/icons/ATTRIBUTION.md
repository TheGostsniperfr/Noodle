# Icon attribution

Every file in this directory is compiled into the `noodle` binary. The Apache-2.0 license
of the noodle code (see `LICENSE`) does not cover the logos below: each one is listed with
where it comes from and under which terms. `go test ./assets/` fails when a file has no row
here, or a row has no source URL or no license.

All logos are trademarks of their owners and are used only to name the product they
depict. Using a logo in a diagram does not imply endorsement by its owner. Check the
owner's brand rules before using a logo outside a diagram of their product.

Notes on the sources:

- `python.svg` and `sonarqube.svg` come from an older revision of simple-icons; upstream
  has since renamed or redrawn them (`sonarqube` is now `sonarqubeserver`).
- `velero.svg` is the CNCF file without its XML declaration.
- `envoy-gateway.svg` is a copy of the Envoy icon.
- `grafana-alloy.svg` is adapted from the Alloy icon: other colours and canvas.
- `loki.svg` and `dagster.svg` are the owners' marks as published on their sites; the
  exact upstream file was not recorded when they were added.
- `globe`, `rack` and `user` were drawn for noodle.
- Monochrome simple-icons files carry a `fill` added for the brand colour.

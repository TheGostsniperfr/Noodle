# CLI reference

Generated by `make cli-doc` from the output of `noodle help`; do not edit it by hand.
`go test ./cmd/noodle/` fails when this page differs from that output.

```text
usage: noodle render DIR [-view ID] [-o out.drawio] [-theme dark|light] [-icons DIR[,DIR]] [-slide]
       noodle migrate SPEC.yaml DIR   (a v0 single file to a v1alpha1 system)
       noodle discover ADAPTER [PATH…|-] [-o fragment.yaml]
       noodle setup opencode|codex (-project [DIR] | -user)
       noodle version
       noodle help [-markdown]
       noodle -list-icons [-icons DIR[,DIR]]

noodle render DIR
  Check a view and its lint; with -o, write it as a draw.io file. A sequence view is checked on its participants only.
  -icons string
    	comma-separated directories of extra <name>.svg icons
  -o string
    	output .drawio path (lint only when empty)
  -slide
    	drawing only, cropped to its content: no header, cards or notes
  -theme string
    	dark or light (default "dark")
  -view string
    	view id, the file stem in views/ (optional when the system has one view)

noodle discover ADAPTER [PATH…|-]
  Read infrastructure files (no path or - reads stdin) and write a fragment of what they define. Adapters: k8s.
  -namespace string
    	namespace of objects that name none, as kubectl apply -n (default: default)
  -o string
    	output fragment path, usually <system>/discovered/<adapter>-<source>.yaml (stdout when empty)
  -observed-at string
    	observation time, RFC 3339 (now when empty)
  -ref string
    	version of the source, e.g. a Git commit

noodle migrate SPEC.yaml DIR
  Convert a v0 single file to a v1alpha1 system, and write nothing unless it draws the same diagram.

noodle setup opencode|codex
  Write the noodle-diagram skill and the subagents where OpenCode or Codex read them. Exactly one of -project and -user; -project takes an optional DIR.
  -project
    	write under DIR (default .)
  -user
    	write under the home directory

noodle version
  Print the version set at build time: a release tag, a Nix revision, or dev.

noodle help
  Print this reference. With -markdown, print docs/guide/cli.md.

noodle -list-icons
  List the icon names a view can use.
  -icons string
    	comma-separated directories of extra <name>.svg icons, searched before the built-in ones
  -list-icons
    	print the available icon names and exit
```
